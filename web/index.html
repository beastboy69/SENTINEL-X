No live collection attempt yet.
Live collection reads event metadata from the last 15 minutes and polls every 30 seconds while enabled. It is not a full EDR and may not detect attacks. The server binds to localhost by default; do not expose it publicly without authentication, authorization, TLS, and a security review.
Personal security analyst

Phishing, privacy and credential exposure checks.

These tools perform local heuristic analysis or contact the explicitly named breach-check service. Findings are leads, not proof of compromise. Scans never modify files.

Phishing URL analyser

Checks URL structure, suspicious hostname patterns and DNS resolution. It does not open the link or verify reputation.

Phishing email analyser

Paste email text or headers. Text-based indicators only; do not paste confidential content you cannot share.

Local data exposure scan

Scans a folder you choose for text-file patterns that may indicate secrets or personal data. Values are not displayed, uploaded or stored.

Password breach check

Uses the Pwned Passwords range API with k-anonymity. Your password and full hash are not sent. Internet connection required.

Password is held only in this page until you clear it; it is not saved by this app.
